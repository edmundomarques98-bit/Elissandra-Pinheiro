# Elissandra Pinheiro — Psicanalista Clínica

Site institucional responsivo com a identidade visual original, informações sobre atendimento online e presencial e contato pelo WhatsApp.

## Estrutura

- `index.html`: conteúdo da página.
- `styles.css`: identidade visual e layout responsivo.
- `app.js`: menu móvel e animações.
- `assets/`: logo vetorial, símbolo e imagem otimizada em WebP.

## Executar localmente

Na pasta do projeto, execute `python3 -m http.server 8000` e acesse `http://localhost:8000`.

Não é necessário instalar dependências nem compilar o site.

## GitHub Pages

Os arquivos estão na raiz, prontos para usar o branch `main` e a pasta `/ (root)` como origem em Settings → Pages. A publicação depende de essa configuração ser ativada no repositório.

A imagem de ambiente é conceitual, e não uma fotografia do consultório. A identidade visual e o conteúdo pertencem aos seus respectivos titulares.
